# 월계 보행지도 — 웹 프로토타입 (프론트엔드)

주민이 계단·단차 같은 보행 불편 구간을 사진·GPS·태그로 제보하고, 지도에서 확인하는 서비스의 화면입니다.
앱 개발 환경이 정해지기 전까지, 모바일 폭(390px) 기준의 웹 프로토타입으로 진행합니다.

- 지도: Leaflet + OpenStreetMap
- 서버: 저장소 맨 위 폴더의 백엔드 (API 설명은 [../../API.md](../../API.md))
- 별도 빌드 도구 없이 HTML/CSS/JS 파일만 사용합니다.

## 구현 현황

| 화면 | 상태 |
|---|---|
| 지도 메인 (현재 위치, 태그별 색상 마커) | 완료 |
| 마커 팝업 (사진, 태그, 등록일, 제보자 닉네임) | 완료 |
| 로그인·회원가입 | 예정 (3단계) |
| 제보 등록 | 예정 (4단계) |
| 제보 완료 | 예정 (4단계) |
| 상단 필터 칩, 포인트, 경로 추천 | 구상만 (코드 없음) |

## 실행 방법

먼저 백엔드를 켜고, 그다음 화면을 엽니다.

1. **백엔드 실행** — 저장소 맨 위 폴더에서 (`.env` 설정과 `npm run migrate`는 [../../README.md](../../README.md) 참고)
   ```
   npm start
   ```
   `http://localhost:3000/health`가 `{"status":"ok"}`를 돌려주면 정상입니다.
   테스트할 때는 `.env`의 `REGION_RADIUS_KM=50`으로 두면 어디서든 제보할 수 있습니다.

2. **화면 실행** — 저장소 맨 위 폴더에서 새 CMD 창을 열고
   ```
   npx serve -l 5500 frontend/web
   ```

3. 크롬에서 `http://localhost:5500`을 열고 위치 권한을 **허용**합니다.
   폰 화면처럼 보려면 `F12` → 기기 툴바 아이콘 → 폭 390으로 맞춥니다.

파일을 더블클릭해서 열면 위치 권한이 막힐 수 있으니 위 주소로 여는 것을 권장합니다.

## 폴더 구조

```
frontend/web/
  index.html       화면 뼈대와 script 연결
  css/style.css    스타일
  js/config.js     BASE_URL(서버 주소), 처음 지도 위치, 마커 색
  js/api.js        서버 호출
  js/map.js        지도, 마커, 팝업, 현재 위치
  js/main.js       시작점
```

`index.html`은 스크립트를 `config → api → map → main` 순서로 불러옵니다.
앞 파일의 함수를 뒤 파일이 쓰므로 순서를 바꾸면 동작하지 않습니다.
로그인·제보 기능을 만들 때 `js/auth.js`, `js/report.js`를 추가할 예정입니다.

## 서버 주소 바꾸기

`js/config.js` 맨 위의 `BASE_URL` 한 곳만 고치면 됩니다.

```js
const BASE_URL = 'http://localhost:3000';
```

## 마커 색 규칙

| 색 | 의미 | 태그 분류 |
|---|---|---|
| 주황 | 물리적 장애 | physical (계단, 단차, 급경사 등) |
| 황색 | 임시 장애물 | temp (공사 중, 적치물) |
| 초록 | 여성 안심길 | safety_path |
| 회색 | 그 외 | 조명 불량 등 (색 미정) |

태그가 여러 개인 제보는 **물리적 > 임시 > 안심길** 순서로 색을 정합니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결할 수 없어요" 안내 | 백엔드가 켜져 있는지, `BASE_URL`이 맞는지 |
| 파란 현재 위치 점이 안 보임 | 위치 권한 허용 여부, `http://localhost:5500`으로 열었는지 |
| 화면이 예전 그대로 | `Ctrl + Shift + R`로 강제 새로고침 |
| 마커가 하나도 없음 | 정상입니다. 아직 등록된 제보가 없는 것 (제보 기능은 4단계) |
