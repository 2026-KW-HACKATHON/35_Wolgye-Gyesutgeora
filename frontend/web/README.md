# 월계동행 — 웹 프로토타입 (프론트엔드)

주민이 계단·단차 같은 보행 불편 구간을 사진·GPS·태그로 제보하고, 지도에서 확인하는 서비스의 화면입니다.
앱 개발 환경이 정해지기 전까지, 모바일 폭(390px) 기준의 웹 프로토타입으로 진행합니다.

- 지도: Leaflet + OpenStreetMap
- 서버: 저장소 맨 위 폴더의 백엔드 (API 설명은 [../../API.md](../../API.md))
- 별도 빌드 도구 없이 HTML/CSS/JS 파일만 사용합니다.

## 구현 현황

| 화면 | 상태 |
|---|---|
| 지도 메인 (현재 위치, 태그별 색상 마커) | 완료 |
| 마커 팝업 (사진, 태그, 등록일, 제보자 닉네임) | 완료 |
| 로그인·회원가입 (중복 확인, 자동 로그인, 로그인 유지) | 완료 |
| 제보 등록 (사진 1~3장, 현재 위치, 태그, 설명) | 완료 |
| 제보 완료 (등록 확인, 포인트 안내 문구) | 완료 |
| 보행환경 필터 (통행 상태, 불편 유형) | 완료 |
| 포인트 사용, 경로 추천 | 구상만 (코드 없음) |

## 실행 방법

먼저 백엔드를 켜고, 그다음 화면을 엽니다.

1. **백엔드 실행** — 저장소 맨 위 폴더에서 (`.env` 설정과 `npm run migrate`는 [../../README.md](../../README.md) 참고)
   ```
   npm start
   ```
   `http://localhost:3000/health`가 `{"status":"ok"}`를 돌려주면 정상입니다.
   테스트할 때는 `.env`의 `REGION_RADIUS_KM=50`으로 두면 어디서든 제보할 수 있습니다.

2. **화면 실행** — 저장소 맨 위 폴더에서 새 CMD 창을 열고
   ```
   npx serve -l 5500 frontend/web
   ```

3. 크롬에서 `http://localhost:5500`을 열고 위치 권한을 **허용**합니다.
   폰 화면처럼 보려면 `F12` → 기기 툴바 아이콘 → 폭 390으로 맞춥니다.

파일을 더블클릭해서 열면 위치 권한이 막힐 수 있으니 위 주소로 여는 것을 권장합니다.

## 폴더 구조

```
frontend/web/
  index.html       화면 뼈대와 script 연결
  css/style.css    스타일
  js/config.js     BASE_URL(서버 주소), 처음 지도 위치, 마커 색
  js/api.js        서버 호출, 오류 code별 안내 문구
  js/map.js        지도, 마커, 팝업, 현재 위치
  js/auth.js       로그인 상태 저장, 상단 로그인 표시, 로그인·회원가입 창
  js/report.js     제보 등록 창, 제보 완료 화면
  js/filter.js     보행환경 필터 창
  js/main.js       시작점
```

`index.html`은 스크립트를 `config → api → map → auth → report → filter → main` 순서로 불러옵니다.
앞 파일의 함수를 뒤 파일이 쓰므로 순서를 바꾸면 동작하지 않습니다.

## 필터 동작

- 지도 오른쪽 아래 **필터** 버튼 → 통행 상태(통행 가능/불편/불가)와 불편 유형(계단, 단차 등)을 고르는 창이 열립니다.
- 서버에 다시 요청하지 않고, 이미 받은 제보를 화면에서 걸러 냅니다. 버튼을 누르는 즉시 지도가 바뀝니다.
- 규칙: **같은 항목 안에서는 하나라도 맞으면(OR), 항목이 다르면 둘 다 맞아야(AND)** 보입니다.
  예) 통행 불가 + 통행 불편 + 계단 → (통행 불가 또는 통행 불편)이면서 계단이 있는 제보
- 아무것도 고르지 않은 항목은 제한하지 않습니다. **초기화**를 누르면 전체가 다시 보입니다.
- 조건을 고르면 필터 버튼이 파랗게 바뀌고 조건 개수가 표시됩니다. 결과가 0건이면 안내가 뜹니다.
- 통행 상태를 입력하지 않은 옛 제보는 통행 상태 필터를 걸면 보이지 않습니다.
- 규칙은 `js/map.js`의 `matchesFilter`, 화면은 `js/filter.js`입니다.

## 제보 등록 동작

- 제보하기 버튼 → (로그인 안 했으면 로그인 창) → 제보 창이 열립니다.
- 위치는 창이 열릴 때 GPS로 자동 입력합니다. 실패하면 "다시 확인" 버튼으로 재시도합니다. (지도에서 직접 위치 선택은 아직 없음)
- 사진은 1~3장, jpg/png/webp/heic, 장당 10MB 이하입니다. (서버 규칙과 같음)
- **통행 상태**(통행 가능 / 통행 불편 / 통행 불가)는 **필수, 하나만 선택**합니다. 선택한 값은 전용 칸
  `accessibility_status`와 태그 양쪽에 함께 보냅니다. 지도 팝업에는 색이 있는 "통행 상태" 표시로 나옵니다.
- 나머지 태그(불편 유형)는 1개 이상 선택하고, 서버(`GET /api/tags`)에서 받아 오므로 서버에 태그가 추가되면 폼에 자동으로 나타납니다.
  새 분류(category)가 생기면 `js/report.js`의 `CATEGORY_LABELS`에 제목을 추가하세요. 없으면 "기타"로 묶입니다.
- 서비스 지역 밖이면(`OUT_OF_REGION`) 떨어진 거리와 허용 반경을 안내합니다.
- 등록에 성공하면 제보 완료 화면이 나오고, "지도에서 확인하기"로 새 마커로 이동합니다.
- 포인트는 아직 지급되지 않으며, 완료 화면에는 "승인되면 지급될 예정" 안내만 보여줍니다.

## 로그인 동작

- 가입은 아이디 + 닉네임 + 비밀번호이고, 성공하면 바로 로그인됩니다. (개인정보는 받지 않음)
- 규칙: 아이디 영문·숫자·밑줄 4~20자(대문자는 소문자로 저장), 닉네임 2~20자, 비밀번호 8자 이상
- 가입 화면의 "비밀번호 확인" 칸은 입력하는 즉시 일치 여부를 보여주며, 화면에서만 쓰고 서버로는 보내지 않습니다.
- 토큰은 브라우저(localStorage)에 저장되어 새로고침해도 유지되고, 유효기간은 7일입니다.
- 제보하기 버튼은 로그인하지 않았으면 로그인 창을 먼저 띄웁니다.
- 비밀번호 찾기는 없습니다. (본인 확인용 개인정보를 받지 않기 때문)

## 승인된 제보만 표시

지도에는 **승인된(`approved`) 제보만** 표시합니다. (`js/config.js`의 `REPORT_STATUS`)
새로 등록한 제보는 `pending`(검토 중)이라서, 승인되기 전에는 지도에 나타나지 않습니다.
전체를 보고 싶으면 `REPORT_STATUS`를 `''`(빈 문자열)로 바꾸세요.

아직 관리자 승인 화면·API가 없어서, 승인은 DB에서 상태를 직접 바꿔서 합니다. (`reports.status`를 `approved`로)

## 오류 처리

| 상황 | 화면 동작 |
|---|---|
| 서버에 연결 안 됨 / 지도 데이터 로딩 실패 | 안내와 **다시 시도** 버튼 (`main.js`의 `loadMapData`) |
| 위치 권한 거부 / 위치 확인 실패 | 지도는 기본 위치(월계1동)로 계속 사용, **내 위치** 버튼으로 재시도 |
| 지도 그림(타일) 로딩 실패 | 한 번만 안내 |
| 팝업 사진 로딩 실패 | "사진을 불러오지 못했어요" 표시 |
| 로그인 실패, 가입 중복·형식 오류 | 해당 입력칸 아래에 안내 |
| 로그인 만료 | 로그인 창 다시 표시 (제보 작성 내용은 유지) |
| 서비스 지역 밖 제보 | 떨어진 거리와 허용 반경 안내 (`OUT_OF_REGION`) |
| 사진 형식·용량 오류 | 서버 규칙(jpg/png/webp/heic, 10MB)과 같은 기준으로 미리 안내 |
| 제보 등록 실패 | 오류 안내 후 작성 내용을 유지한 채 다시 등록 가능 |

오류 코드별 문구는 `js/api.js`의 `ERROR_MESSAGES`, `errorMessage()`에서 관리합니다.

## 서버 주소 바꾸기

`js/config.js` 맨 위의 `BASE_URL` 한 곳만 고치면 됩니다.

```js
const BASE_URL = 'http://localhost:3000';
```

## 마커 색 규칙

| 색 | 의미 | 태그 분류 |
|---|---|---|
| 주황 | 물리적 장애 | physical (계단, 단차, 급경사 등) |
| 황색 | 임시 장애물 | temp (공사 중, 적치물) |
| 초록 | 여성 안심길 | safety_path |
| 회색 | 그 외 | 조명 불량 등 (색 미정) |

태그가 여러 개인 제보는 **물리적 > 임시 > 안심길** 순서로 색을 정합니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결할 수 없어요" 안내 | 백엔드가 켜져 있는지, `BASE_URL`이 맞는지 |
| 파란 현재 위치 점이 안 보임 | 위치 권한 허용 여부, `http://localhost:5500`으로 열었는지 |
| 화면이 예전 그대로 | `Ctrl + Shift + R`로 강제 새로고침 |
| 마커가 하나도 없음 | 정상입니다. 아직 등록된 제보가 없는 것 (제보 기능은 4단계) |
